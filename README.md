¡Hola! Soy Leonardo, Desarrollador de Software apasionado por la tecnología, la programación y la creación de soluciones digitales.

Cuento con experiencia en el desarrollo, mantenimiento y optimización de sistemas empresariales, así como en la creación de aplicaciones web y la integración de servicios Backend y Frontend.

Me interesa diseñar soluciones eficientes, explorar nuevas tecnologías y afrontar desafíos que me permitan seguir creciendo profesionalmente.

- 💻 Desarrollo de software y aplicaciones web.
